# wet-mcp (renamed)

**This distribution has been renamed to [`n24q02m-wet`](https://pypi.org/project/n24q02m-wet/).**

`wet-mcp` is now a transitional stub: installing it installs `n24q02m-wet` and keeps the
legacy `wet-mcp` command pointing at the same entry point, so existing
`uvx wet-mcp` and `pip install wet-mcp` setups keep working. Please switch to:

```bash
uvx n24q02m-wet
pip install n24q02m-wet
```

No further releases of `wet-mcp` are planned beyond this stub. Source and issues:
https://github.com/n24q02m/wet
